# Repository research register

**Status: candidate inventory only. No repository or dependency is approved for production.**

This register transcribes Appendix A of the founder-provided production prompt so every function can be reviewed before adoption. Prompt labels such as `PICK` are source-document suggestions, not this project approval. Runtime compatibility with Cloudflare Workers, current release/maintenance, security advisories, license obligations, feature fit, and integration costs remain to be checked against primary sources before any adoption.

Source inventory: 61 functional categories, 183 repository placements, and 165 unique GitHub repositories. Categories marked Later in the source remain included because the founder selected all categories for day one.

## Pre-adoption review required for each candidate

- Verify the exact repository, current stable release, release date, supported runtime/version, and required services from official documentation/source.
- Review license and transitive dependency obligations for the version considered.
- Check current security advisories, maintenance activity, and known production limitations.
- Test only after architecture and repository use are approved; confirm fit for Jordan workflows, Arabic/RTL, seller isolation, payment/fulfillment, and Cloudflare/Supabase constraints.
- Record one of: adopt, adapt a pattern only, reject, or not applicable, with evidence and owner approval.
