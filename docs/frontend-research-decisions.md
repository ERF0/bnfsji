# Frontend research and decisions

Checked 2026-10-26. Public documentation was retrieved; competitor flows were not clicked end to end. `DOCUMENTED` describes the linked source, while `VERIFIED` describes this repository or local browser.

| Problem → evidence and convention | Bnafsaji decision → validation | Confidence |
|---|---|---|
| Seller product work needs a clear Products entry. [Shopify product help](https://help.shopify.com/en/manual/products/add-update-products/) documents add/update from Products; [status help](https://help.shopify.com/en/manual/products/details/product-details-page/) distinguishes drafts and active listings. | Keep the existing seller Products route and truthful “Publish” label; do not present Save draft while the current RPC publishes immediately. Record draft support as a backend gap. | DOCUMENTED source; VERIFIED repository RPC |
| Staff navigation should reflect tasks and permissions. [Shopify admin guidance](https://help.shopify.com/en/manual/shopify-admin/shopify-admin-overview) documents role-based access to areas of work. | Keep the existing role-specific portal navigation; remove the buyer bottom bar from staff workspaces and restore Arabic overview links. Browser check in both locales. | DOCUMENTED source; VERIFIED local route behavior |
| Waiting and errors need visible, programmatic feedback. [W3C status-message guidance](https://www.w3.org/WAI/WCAG21/Understanding/status-messages) describes status roles; [error identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification) requires text describing detected errors. | Use `useNavigation` pending state, disable repeat submission and show bilingual `role="status"` text on existing seller forms. Authenticated submission/screen-reader testing remains open. | DOCUMENTED standard; local code verified by build |
| Workspace screens need readable links and a way out of signed-out states. [WCAG 2.2](https://www.w3.org/TR/wcag/) defines minimum contrast and target criteria. A local 390px screenshot exposed the dark inactive navigation links. | Correct the specific CSS override and link signed-out entry points to the existing account route. Browser-test the links; visually inspect both workspace locales. | DOCUMENTED standard; VERIFIED local issue and fix |
| Buyer discovery should expose genuine merchandise. The [SHEIN Jordan category page](https://jo.shein.com/women-dresses-c-1727.html) documents size/color/JOD facets. | Extend the existing public catalog RPC with live shop, fulfillment and option filtering. Derive available choices and counts from published products and eligible variants; keep sample inventory explicitly labeled. | DOCUMENTED page; VERIFIED local PostgreSQL behavior; hosted behavior unverified |
| [Shopify customer accounts](https://help.shopify.com/en/manual/customers/customer-accounts) document signed-in editing of shipping addresses in the account profile. | Place an Amman-only address book under the existing buyer account, with add/edit/remove controls and RLS. Do not auto-fill checkout until an order flow exists. | DOCUMENTED source; VERIFIED local RLS and signed-out/unconfigured browser state |
| [Shopify store details](https://help.shopify.com/en/manual/your-account/manage-orgs-and-stores/manage-store-details?lang=en) place editable store details under settings and keep the store domain unchanged when its name changes. | Add an owner-scoped shop profile with bilingual names and descriptions; keep the approved slug stable and render descriptions on the public shop page. | DOCUMENTED source; VERIFIED local owner-only SQL behavior; hosted save unverified |

Alternatives rejected for this slice: a new UI library, a parallel workspace shell, and mock order/support pages. Existing navigation and form components solve the observed issues with smaller changes.
